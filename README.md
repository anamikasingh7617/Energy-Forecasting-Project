# Energy Consumption and Renewable Energy Production Analysis and Forecasting

## 📌 Project Overview

This project analyzes energy consumption and renewable energy production data. It includes data preparation, data cleaning, exploratory data analysis, demand prediction, and an interactive dashboard for visualizing energy-related insights.

## 🚀 Features

- Energy demand data analysis
- Renewable energy production analysis
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Energy demand prediction using a machine learning model
- Interactive dashboard for data visualization
- Energy balance analysis

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Streamlit

## 📁 Project Files

- `prepare_data.py` – Prepares the dataset
- `clean_data.py` – Cleans and preprocesses the data
- `eda.py` – Performs exploratory data analysis
- `train_model.py` – Trains the machine learning model
- `predict.py` – Generates energy demand predictions
- `demand_model.pkl` – Saved trained model
- `feature_columns.pkl` – Saved feature information
- `app.py` – Streamlit dashboard application

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Install the required Python libraries.
3. Run the data preparation and model scripts if required.
4. Start the Streamlit dashboard using:

```bash
streamlit run app.py
```

## 📊 Project Outcome

The project provides insights into energy consumption and renewable energy production. It also uses machine learning to support energy demand forecasting and presents the results through an interactive dashboard.
